# 企业级企业卡对账结算

版权所有 © 2026 上海如静知华信息科技有限公司（[知华科技官网](https://www.zhuatech.cn/)）。

## 适用范围

面向企业采购卡、差旅卡及虚拟卡的月度账单对账，避免缺票、重复报销、个人消费未归还、错误税务分类或总账不平时直接结算。

## 结算门禁

- 完整导入账单，并以卡号令牌映射持卡员工，不保存明文卡号。
- 校验票据、商户/日期/金额匹配、重复风险、政策例外和税务分类。
- 校验成本中心、个人消费归还、总账过账预览、财务批准和职责分离。
- 员工提醒、异常行为复核和月结归档包作为可跟踪行动项。

## 接口与决策

`POST /api/enterprise/expense/corporate-card-reconciliation`

返回 `SETTLE`、`REVIEW` 或 `BLOCKED` 及其可解释原因。银行、卡组织、税务和总账系统仅预留标准适配方式，部署方需自行配置。
